# Sistema de Administración de Citas para Consultorio Clínico

Este proyecto es una aplicación de consola en Java que permite gestionar doctores, pacientes y citas en un consultorio médico.

## Instalación y configuración

1. Asegúrate de tener **Java 8 o superior** instalado en tu sistema.
2. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/angel666x/Evidencia-Final.git

Uso del programa
Al ejecutar el programa, se te solicitará iniciar sesión.

Usuario: Admin
Contraseña: 123456

Una vez dentro del sistema, podrás:

Dar de alta médicos.
Dar de alta pacientes.
Crear citas médicas asociadas a médicos y pacientes.
Consultar los registros.

Los datos quedan guardados en archivos CSV dentro de la misma carpeta del proyecto:
medicos.csv
pacientes.csv
citas.csv
